
# Automatic File Organizer using Python

## Project Overview
The Automatic File Organizer is a mini Python project that automatically organizes files into different folders based on their file extensions.

It helps reduce manual work and keeps files organized.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- OS Module
- Shutil Module

## Project Features
- Automatically identifies file extensions.
- Creates folders automatically.
- Moves files into appropriate folders.
- Organizes PDF, Excel, Images, Word and Text files.
- Generates a CSV report.
- Displays organized files.

## Folder Structure

- PDF
- Excel
- Images
- Word
- Text

## Python Concepts Used
- Variables
- For Loop
- If-Else Conditions
- File Handling
- OS Module
- Shutil Module
- Pandas DataFrame
- CSV File Handling

## How to Run the Project

1. Download or clone this repository.
2. Open Jupyter Notebook.
3. Open `Automatic_File_Organizer.ipynb`.
4. Update the folder path according to your system.
5. Run all cells.

## Output
Files are automatically moved into separate folders based on their extensions.

A CSV report is also generated to show organized file names and categories.
